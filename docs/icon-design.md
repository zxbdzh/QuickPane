# QuickPane 图标设计规格

## 目标

为 QuickPane 建立一套统一的产品图标，覆盖桌面安装包、任务栏/窗口、favicon 和新标签页标识。图标需要在 Windows 10/11 的亮色与暗色环境中保持稳定识别，并在 16px 的任务栏尺寸下仍能看出双层面板结构。

## 已确认方向

- 图形母题：折叠面板
- 构造方案：双折面 Q
- 配色取向：蓝琥珀双色
- 交付范围：统一全部入口
- 图标不包含文字

## 视觉系统

### 构图

- 母版画布为 `1024 x 1024`。
- 外层是深墨蓝方形底板，底板四周保留约 12% 安全区。
- 底板圆角约为底板边长的 18%，只用于外轮廓，不添加投影或描边。
- 蓝色面板位于左上方向，构成粗 `L` 形折页。
- 琥珀面板位于右下方向，构成同宽的镜像折页。
- 两块面板在中心区域咬合，不使用透明叠加。
- 中心负形至少占图标宽度的 16%，末端向右下略延伸，形成隐性的 `Q` 尾部。
- 面板外侧保留直角边，内侧使用统一的大圆角；不使用细线、复杂切口或微小装饰。

### 颜色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Ink | `#16233D` | 底板与中心负形 |
| Pane Blue | `#3E82F7` | 左上折页 |
| Signal Amber | `#F4B942` | 右下折页 |
| Paper | `#F7F9FC` | 仅作为浅色界面中的适配参考，不改变主图标底板 |

底板固定为 Ink，不随系统主题变色；这样 favicon、任务栏和安装器中的品牌外观一致。

## 资源与接入

### 单一母版

维护一个 SVG 母版 `public/quickpane-mark.svg`，作为所有入口的唯一图形来源：

- `index.html` 引用它作为 favicon。
- `NewTabPage` 使用它替换当前的字母 `Q` 方块。
- Tauri 图标生成命令从它生成桌面资源。

不为 16px 单独维护另一套设计。若小尺寸测试失败，调整母版几何后重新生成全部资源。

## 使用规则

- 图标是静态品牌资产，不添加 hover 动画、主题换色或运行时状态变体。
- 不加入浏览器地球、闪电、键盘按键、文字或额外装饰。
- 新标签页中图标作为装饰性图形使用，`QuickPane` 文本继续承担可读品牌名称；装饰图形不重复朗读品牌名。
- favicon、桌面图标和新标签页使用同一底板版本。

## 验收

1. 母版和生成资源的几何一致，没有手工修改导致的尺寸漂移。
2. `16px`、`32px`、`128px`、`512px` 预览中，蓝色面板、琥珀面板和中心负形均可区分。
3. 所有 Tauri 资源格式和尺寸符合文件名及 Tauri 配置要求。
4. `index.html` 能加载 favicon，生产构建产物包含 SVG 资源。
5. 新标签页显示新图标，布局不发生文字溢出或尺寸跳动。
6. `pnpm build` 通过；资源生成命令和必要的 Rust 检查通过。

## 范围边界

本规格只定义 QuickPane 的静态产品图标，不改应用主题色、不重做导航栏图标、不新增品牌字体或独立营销插图。
